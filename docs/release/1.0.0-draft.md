# EvalGate 1.0.0 release notes — draft only

> Status: **not released**. This document is a review draft, not a tag, publication, package
> release, image publication, or deployment announcement.

## Proposed R3 scope

EvalGate's first stable R3 cut combines the governed corpus and idempotent PostgreSQL ingestion,
explainable hybrid retrieval, grounded cited answers over a frozen POST/fetch/SSE contract, local
inspection and read-only results views, reviewed retrieval regression evidence, and a governed
manual live-generation evaluation path. It also includes the public-mode application boundary,
browser-content safety/accessibility automation, content-free telemetry and future-generation
controls, plus a local non-root release-candidate image and runbooks.

## Evidence boundary

- Retrieval evidence is real local reference-embedding evidence over the reviewed 36-case corpus;
  fixture output is never presented as model quality.
- The governed OpenRouter run is limitation-heavy and advisory. It does not justify a positive
  generation-quality claim or enable public live generation.
- No public deployment, hosted URL, public release image, tag, or package release exists.

## Release decision

The candidate is blocked and remains at `0.9.0`. Read
[the R3 readiness record](READINESS.md) for the exact evidence, unreviewed scanner waiver,
pending manual accessibility checks, and remote-CI-evidence requirement. This draft must be
replaced by final release notes only after every blocker is closed and the final `1.0.0` image
has been rebuilt and verified.
