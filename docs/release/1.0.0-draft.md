# EvalGate 1.0.0

EvalGate 1.0.0 is the first stable R3 source release. It packages the governed local evaluation product: corpus ingestion, explainable retrieval, grounded cited answers, read-only evaluation results, a responsive inspection/results UI, a real-world Kubernetes documentation showcase, and release evidence for local operation.

## Included

- Governed Northstar corpus and golden retrieval evaluation with a passing 36-case baseline.
- Idempotent PostgreSQL/pgvector ingestion, hybrid retrieval, citation validation, and bounded answer streaming.
- React inspection, results, and showcase views with responsive navigation, light/dark themes, Radix selectors, retryable timeout handling, and accessibility automation.
- Governed OpenRouter live-evaluation workflow and Kubernetes showcase evidence with explicit limitations.
- Public-mode application boundary, route protection, redacted telemetry, local limits, runbooks, and release scripts.
- Final local Docker image smoke evidence for `evalgate-api:1.0.0`, CycloneDX SBOM, dependency audits, and pinned Trivy actionable scan.

## Boundaries

This release is a source-code release. It does not publish a hosted service, public Docker image, package, browser secret, cloud storage path, or deployment. Fixture answers are contract evidence only, and the governed live-provider artifacts remain limitation-heavy; they are not generation-quality success claims.
