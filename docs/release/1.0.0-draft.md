# EvalGate 1.0.0 release notes — draft only

> Status: **not released**. This is a review draft, not a tag, publication, package release, image
> publication, deployment announcement, or WCAG conformance claim.

## Proposed R3 scope

EvalGate's first stable R3 cut combines the governed corpus and idempotent PostgreSQL ingestion,
explainable hybrid retrieval, grounded cited answers over a frozen POST/fetch/SSE contract, local
inspection and read-only results views, reviewed retrieval regression evidence, and a governed
manual live-generation evaluation path. It also includes the public-mode application boundary,
browser-content safety/accessibility automation, content-free telemetry and future-generation
controls, a responsive product shell that explains the evidence flow with human-readable
identities and recoverable states, a pinned and attributed real-world documentation showcase with
governed multi-model evidence, plus a local non-root release-candidate image and runbooks. The
product-experience, real-world-showcase, and product-shell/onboarding portions are merged; their
presence does not override failed release gates.

## Evidence boundary

- Retrieval evidence is real local reference-embedding evidence over the reviewed 36-case corpus;
  fixture output is never presented as model quality.
- The governed OpenRouter run is limitation-heavy and advisory. It does not justify a positive
  generation-quality claim or enable public live generation.
- The real-world showcase must identify the immutable source revision and license, distinguish
  authored review questions from production traffic, compare only compatible model capabilities,
  and publish human review and limitations alongside aggregate results.
- No public deployment, hosted URL, public release image, tag, or package release exists.

## Release decision

The merged `0.12.2` candidate now passes exact-main CI, the unchanged 36-case retrieval baseline,
dependency audits, non-root image smoke, CycloneDX SBOM generation, and the pinned Trivy actionable
scan. The complete scan still discloses 44 upstream-unfixed HIGH findings under ADR-0014; the image
is not described as vulnerability-free.

The stable release remains blocked at `0.12.2`. Showcase has document-level horizontal overflow at
320 CSS pixels, and the required human screen-reader, keyboard, 200% zoom, and forced-colors review
is incomplete. Those gates must close before EG-014 may apply `1.0.0` and rebuild final evidence.
