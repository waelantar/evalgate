# Archived Northstar Release Notes 1.8

## Archive status
These fictional release notes are historical and intentionally include obsolete operational facts. They are not the current release procedure.

## Former cache guidance
Release 1.8 allowed Board API clients to cache status summaries for 60 seconds. The current Board API contract limits caching to 15 seconds.

## Former notification guidance
Release 1.8 described two delivery retries. The current notification policy permits three bounded retries for temporary destination failure.

## Former staleness guidance
Release 1.8 mentioned a 20-minute staleness display threshold. The current Status Ledger policy uses 30 minutes.

## Historical context
The former thresholds reflected a limited pilot. They remain in this archive only to make revision-aware retrieval and citation review measurable.

## No configuration authority
Release notes summarize a completed change; they do not authorize a future deployment or override a current policy document.

## Citation trap
A retrieved numeric threshold must be checked against its document status. A coherent old number is still the wrong answer to a current-policy question.

## Unanswerable boundary
These notes do not provide release dates, customer counts, incident counts, regions, vendors, or real performance measurements.
